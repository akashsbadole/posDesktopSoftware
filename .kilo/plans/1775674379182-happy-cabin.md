# Plan to Fix User Registration Error

## Problem Analysis
The error "An error occurred during registration" occurs because the frontend calls `dbUpsertUser` which invokes a Tauri command "upsert_user", but this command does not exist in the backend.

Additionally, there's a mismatch between the User struct in Rust (db.rs) and TypeScript (db.ts):
- Rust User: id, name, role, store_id
- TS User: id, organization_id?, name, email, role, store_id?, hourly_rate, pin?, password?

The users table has: id, organization_id, pin, name, email, role, store_id

## Solution Steps

1. **Update User struct in db.rs** to include all fields from the database table:
   - Add organization_id: Option<String>
   - Add email: String  
   - Add pin: String

2. **Update get_users query** in db.rs to select organization_id, email, pin fields

3. **Implement upsert_user function** in db.rs that handles INSERT ... ON CONFLICT ... DO UPDATE for users table, including password hashing for pin field

4. **Add upsert_user command** in main.rs with proper parameter handling

5. **Register upsert_user command** in the invoke_handler list

6. **Test the user registration functionality** to ensure it works correctly

## Files to Modify
- src-tauri/src/db.rs: Update User struct, get_users, add upsert_user
- src-tauri/src/main.rs: Add upsert_user command function and register it

## Verification
Run the application and attempt to add a new user through the staff management interface. The registration should succeed without errors.
