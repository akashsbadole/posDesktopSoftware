## 11. FAQ Section

**H2: Frequently Asked Questions**

### Is POS Billing really free?
Yes. 100% free, no hidden fees, no subscriptions, no transaction charges. All features are included. Forever.

### Does it work without internet?
Yes. Core POS functions work 100% offline. Cloud sync is optional.

### Where is my data stored?
On your device, in a SQLite database file. You own it completely. Optional encrypted cloud backup available.

### Can I use it for multiple stores?
Yes. Multi-store management is free. Create unlimited stores, each with isolated data.

### Is it open source?
Yes. MIT License on GitHub. You can modify, self-host, contribute.

### What about GST compliance?
GST-ready with GSTR-1 and GSTR-3B export. Configurable tax rates, place of supply, customer GSTIN. Also supports VAT, Sales Tax, HST, and 30+ other tax systems.

### Does it support barcode scanners?
Yes. Any USB or Bluetooth barcode scanner that acts as keyboard input (HID mode) works plug-and-play.

### Which printers are compatible?
Any ESC/POS compatible thermal printer. Also works with regular inkjet/laser printers for PDF receipts.

### How do I backup my data?
Copy the `pos.db` file from app data folder, or use the built-in Backup/Restore feature in Settings.

### Is there support?
Free community support via GitHub Issues. Premium paid support plans available for businesses.

### Can I add custom features?
Yes. Open source - fork and modify, or submit PRs to main repo.

### What OS are supported?
Windows 10+, macOS 10.15+, Linux (Ubuntu 20.04+, Fedora 35+).

### Is it secure?
Yes. PIN-based authentication with rate limiting. Role-based access. Activity audit logs. SQLite encryption available. No remote data transmission without your consent.

### How do updates work?
Automatic update check (optional). Download new installer and replace old version. Your database remains intact.

### Can I import my existing data?
CSV import for products and customers available. Full database migration from other POS requires custom script (contact support).

## 12. Installation Guide (Step-by-Step)

**H2: Installation Walkthrough**

### Windows
1. Download `posbilling-2.0.0-windows-x64.exe`
2. Double-click installer
3. Accept UAC prompt
4. Follow wizard (accept defaults)
5. Launch from Start Menu
6. Enter PIN (default: 1234 for admin)

### macOS
1. Download `.dmg` file
2. Open DMG (macOS may block - click "Open Anyway" in Security Preferences)
3. Drag POS Billing to Applications folder
4. Launch from Applications
5. Enter PIN (default: 1234 for admin)

### Linux
1. Download `.AppImage` or `.deb`/`.rpm`
2. For AppImage: `chmod +x posbilling-*.AppImage`
3. Double-click to run
4. Enter PIN (default: 1234 for admin)

### Post-Installation
1. Complete onboarding wizard (store name, currency, country)
2. Add your products (via CSV import or manual)
3. Create staff accounts
4. Start taking orders!
